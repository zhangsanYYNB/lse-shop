# 🛒 商店系统插件 - 使用说明

## 📦 插件概述

商店系统插件旨在为生存服务器提供基本的购买、出售和自动售出功能。目前支持物品分类、搜索、表达式计算等功能。虽然功能还在不断完善中，但基本可以满足日常使用需求。如果在使用过程中遇到问题，欢迎反馈。

> **兼容性说明：** 本插件的 `shopdata.json` 配置文件格式兼容 [TMEssential](https://www.minebbs.com/resources/tmessential.2974/) 的商店配置，本插件正是基于 TMEssential 的商店配置文件格式开发的。如果你之前使用过 TMEssential 的商店功能，可以直接使用原有的配置文件。

---

## 🎯 核心功能

### 1. 购买系统
- 从商店购买物品，使用服务器金币
- 支持分类浏览和搜索
- 支持表达式计算购买数量（如 `2*3+1`）
- **支持SNBT物品**：可购买带有自定义NBT数据的物品（如附魔武器、自定义名称物品等）

### 2. 出售系统
- 出售物品获得金币
- 自动检测背包中物品数量
- 支持批量出售
- **支持SNBT物品**：可出售带有自定义NBT数据的物品

### 3. 自动售出系统
- 设置特定物品自动出售
- 定时检查并自动出售设置的物品
- 可配置检查间隔时间

### 4. 搜索功能
- 按名称搜索物品（目前仅支持精确匹配，模糊匹配功能还在开发中）
- 跨分类搜索

### 5. 分类管理
- 支持分类图标
- 灵活的配置结构
- **完全支持多级分类**：支持无限层级的分类嵌套，方便管理大量物品

### 6. 排行榜系统
- 支持查看购买次数、出售次数、购买总额、出售总额排行
- 数据自动统计，无需手动配置
- 通过 `/shop rank` 命令查看

### 7. GUI商店配置（v1.0.4新增）
- 管理员可通过游戏内GUI界面直接管理商店配置
- 无需手动编辑JSON文件，降低配置门槛
- 支持添加/删除分类、添加/删除物品、修改价格
- 支持从背包选择物品快速设置商品
- 操作路径：`/shop open` → 设置系统商店 → 购买/出售

## ⚙️ 配置文件

### 1. 插件配置文件

**位置：** `plugins/shop/config.json`

```json
{
    "AutoSell": true,
    "AutoSellTime": 60
}
```

**配置项说明：**

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `AutoSell` | 布尔值 | `true` | 是否启用自动售出功能 |
| `AutoSellTime` | 数字 | `60` | 自动售出检查间隔（秒） |

---

### 2. 商品数据配置文件

**位置：** `plugins/shop/shopdata.json`

**在线编辑工具：** [shopdata.json 编辑器](https://ai.zhangsanyynb.top/shopdata.html)

#### 配置文件结构

```json
{
    "Buy": [
        {
            "name": "分类名称",
            "type": "group",
            "image": "图标路径",
            "data": [
                {
                    "name": "物品名称",
                    "type": "exam",
                    "image": "图标路径",
                    "data": {
                        "type": "minecraft:物品ID",
                        "aux": 0,
                        "remark": "备注",
                        "money": 价格
                    }
                }
            ]
        }
    ],
    "Sell": [
        // 结构与 Buy 相同
    ]
}
```

#### 字段详细说明

**分类对象（group）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | 字符串 | ✅ | 分类显示名称 |
| `type` | 字符串 | ✅ | 固定值 `"group"` |
| `image` | 字符串 | ❌ | 分类图标路径（可为空） |
| `data` | 数组 | ✅ | 子物品列表 |

**物品对象（exam）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | 字符串 | ✅ | 物品显示名称 |
| `type` | 字符串 | ✅ | 固定值 `"exam"` |
| `image` | 字符串 | ❌ | 物品图标路径（可为空） |
| `data` | 对象 | ✅ | 物品详细信息 |

**物品数据对象（data）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | 字符串 | ✅ | Minecraft 物品ID（如 `minecraft:diamond`） |
| `aux` | 数字 | ❌ | 物品附加值/数据值（购买已支持，出售暂不支持） |
| `remark` | 字符串 | ❌ | 备注信息 |
| `money` | 数字 | ✅ | 价格（金币） |
| `snbt` | 字符串 | ❌ | SNBT字符串（用于自定义NBT物品，与`type`字段二选一） |

```json
                        "snbt": "{Count:1b,Damage:0s,Name:\"minecraft:apple\",tag:{display:{Name:\"§6金苹果\"}}}",
                        "remark": "custom_name_apple",
                        "money": 100
                    }
                }
            ]
        }
    ],
    "Sell": [
        {
            "name": "特殊物品出售",
            "type": "group",
            "image": "",
            "data": [
                {
                    "name": "锋利钻石剑",
                    "type": "exam",
                    "image": "textures/items/diamond_sword.png",
                    "data": {
                        "snbt": "{Count:1b,Damage:0s,Name:\"minecraft:diamond_sword\",tag:{ench:[{id:9s,lvl:5s},{id:17s,lvl:3s}]}}",

                        "money": 4000
                    }
                }
            ]
        }
    ]
}
```

> **SNBT说明：**
> - SNBT（Stringified NBT）是NBT数据的字符串表示形式
> - 使用 `snbt` 字段时，不需要填写 `type` 字段
> - 可通过游戏内命令 `/test` 获取手持物品的SNBT数据
> - SNBT格式参考：[LSE NBT文档](https://lse.levimc.org/zh/apis/NbtAPI/NBT/)

## 🔧 高级功能

### 1. 表达式计算

购买/出售数量支持数学表达式：

```
2*3+1      → 7
10/2       → 5
(2+3)*4    → 20
2^3        → 8
10 mod 3   → 1
```

**支持的运算符：**
- `+` 加法
- `-` 减法
- `*` 乘法
- `/` 除法
- `%` 或 `mod` 取模
- `^` 幂运算
- `()` 括号

**支持的输入格式：**
- 全角/半角数字
- 全角/半角运算符
- 中文括号/英文括号

### 2. 自动售出系统

**工作原理：**
1. 玩家通过商店界面设置要自动售出的物品
2. 系统按配置的时间间隔检查在线玩家
3. 自动出售玩家背包中设置的物品
4. 金币自动添加到玩家账户

**设置方法：**
1. 执行 `/shop open`
2. 选择"自动售出设置"
3. 选择物品分类
4. 开启要自动售出的物品开关

**查看设置：**
```
/shop list    # 查看当前自动售出物品列表
```

### 3. 搜索功能

- 在购买/出售界面点击"搜索"
- 输入物品名称进行搜索
- 搜索结果会显示物品所在分类

> **注意：** 目前搜索功能仅支持精确匹配，暂时还不支持模糊搜索。如果搜索不到结果，请尝试输入完整的物品名称。这个功能后续可能会改进。

### 4. 排行榜功能

**查看方法：**
```
/shop rank    # 打开排行榜界面
```

**支持的排行类型：**
- 购买次数排行榜
- 出售次数排行榜
- 购买总金额排行榜
- 出售总金额排行榜

**统计规则：**
- 所有购买/出售操作自动计入统计
- 自动售出的物品也会计入出售统计
- 数据按玩家维度累计，不会因配置更新而清空

## 🛠️ 安装与部署

### 1. 安装步骤

1. 将 `shop.js` 放入 `plugins/` 目录
2. 创建 `plugins/shop/` 目录
3. 将 `shopdata.json` 放入 `plugins/shop/` 目录
4. 可选：创建 `plugins/shop/config.json` 自定义配置

### 2. 配置步骤

1. 编辑 `shopdata.json` 添加商品
   - 可使用在线编辑器：https://ai.zhangsanyynb.top/shopdata.html
2. 编辑 `config.json` 调整插件设置
3. 重启服务器或重新加载插件

### 3. 重载配置

- 修改 `shopdata.json` 后，系统会自动检测变化
- 如果商品配置发生变化，会清空所有玩家的自动售出设置
- 系统会广播通知玩家重新设置

### 💡 使用技巧

#### 物品ID查找
- 使用游戏内 `/give` 命令查看物品ID
- 参考 Minecraft Wiki 物品ID列表
- 常用物品ID：
  - 钻石：`minecraft:diamond`
  - 铁锭：`minecraft:iron_ingot`
  - 金锭：`minecraft:gold_ingot`
  - 绿宝石：`minecraft:emerald`
  - 红石：`minecraft:redstone`

#### 价格设置建议
- 购买价格 > 出售价格（防止刷金）
- 稀有物品设置较高价格
- 基础资源设置较低价格
- 参考服务器经济平衡

#### 图标设置
- 使用 Minecraft 纹理路径
- 格式：`textures/items/物品名.png`
- 示例：`textures/items/diamond.png`
- 可以为空，使用默认图标

#### SNBT物品配置
- **获取SNBT数据**：在游戏内手持物品，执行 `/shop test` 命令获取SNBT字符串
- **配置格式**：在物品数据中使用 `snbt` 字段代替 `type` 字段
- **适用场景**：附魔武器、自定义名称物品、自定义Lore物品等
- **注意事项**：SNBT字符串必须完整且格式正确，建议使用在线编辑器生成

### ⚠️ 注意事项

1. **备份配置**：修改前建议备份原始 `shopdata.json` 文件，以防万一
2. **格式验证**：请确保导出的 JSON 格式正确
3. **物品ID**：需要使用完整的 Minecraft 物品ID
4. **编码格式**：建议使用 UTF-8 编码保存文件
5. **重启生效**：修改配置后可能需要重启服务器才能生效
6. **aux字段**：购买已支持 aux，出售暂不支持，该功能计划在后续版本完善
7. **多级分类**：完全支持无限层级分类嵌套
8. **SNBT物品**：支持自定义NBT物品，使用`snbt`字段时无需填写`type`字段

### 🔧 常见问题

#### Q1: 为什么自动售出设置被清空了？
A: 当 `shopdata.json` 文件内容发生变化时，系统会自动清空所有自动售出设置，这是为了确保数据的一致性，还请理解。

#### Q2: 如何添加新物品？
A: 可以编辑 `shopdata.json` 文件，在对应的 `Buy` 或 `Sell` 数组中添加新的物品配置。推荐使用在线编辑器，会方便很多。

#### Q3: 支持哪些物品图标？
A: 支持 Minecraft 纹理路径，如 `textures/items/diamond.png`。也可以留空，会使用默认图标。

#### Q4: 如何修改自动售出检查间隔？
A: 编辑 `plugins/shop/config.json` 文件，修改 `AutoSellTime` 值（单位：秒）即可。

#### Q5: 表达式计算支持哪些功能？
A: 支持加减乘除、幂运算、取模、括号，以及全角/半角字符自动转换，应该能满足大部分计算需求。

#### Q6: 编辑器无法加载怎么办？
A: 可以检查一下网络连接，尝试刷新页面，或者换个浏览器试试。

#### Q7: 如何修改已有物品的价格？
A: 在编辑器中找到对应物品，点击编辑按钮修改价格，然后重新导出配置即可。

#### Q8: 导出的文件无法使用？
A: 请检查 JSON 格式是否正确，确保没有语法错误，文件编码建议使用 UTF-8。

#### Q9: 可以同时编辑购买和出售吗？
A: 是的，编辑器支持同时编辑 `Buy` 和 `Sell` 两个部分。

#### Q10: 如何恢复默认配置？
A: 可以使用编辑器的"重置"功能，或者从备份恢复原始文件。

#### Q11: 为什么出售时aux字段不生效？
A: 目前插件购买已支持 aux（物品附加值），但出售功能暂不支持。出售的 aux 支持正在计划中，后续版本会完善。

#### Q12: 多级分类可以使用吗？
A: 是的，插件完全支持多级分类功能。可以创建无限层级的分类嵌套，方便管理大量物品。

#### Q13: 如何添加SNBT物品（自定义NBT物品）？
A: 在配置中使用 `snbt` 字段代替 `type` 字段。可以通过游戏内 `/shop test` 命令获取手持物品的SNBT数据。详细示例请参考配置示例3。

#### Q14: 通过GUI添加的物品名称显示为英文怎么办？
A: 通过GUI从背包选择物品时，物品名称会显示为游戏内部的英文ID（如 `minecraft:diamond`），这是当前版本的已知问题。添加完成后，可以在 `shopdata.json` 中手动修改对应的 `name` 字段为中文名称，或使用在线编辑器修改。

## 🎮 GUI商店配置使用指南（v1.0.4新增）

### 操作入口

1. 执行 `/shop open` 打开商店主界面
2. 如果你是OP（管理员），会看到额外的 **"设置系统商店"** 按钮
3. 点击进入后可选择 **"购买"** 或 **"出售"** 进行配置

### 功能说明

#### 1. 分类管理
- **添加分类**：在分类列表底部点击"添加物品or分类"→ 选择"添加分类"→ 输入分类名称
- **删除分类**：进入要删除的分类 → 点击"删除所在分类" → 确认删除
- **浏览分类**：点击分类名称可进入查看/编辑其中的物品

#### 2. 物品管理
- **添加物品**：在分类中点击"添加物品or分类"→ 选择"添加物品"→ 从背包选择物品
- **删除物品**：点击物品 → 开启"删除物品"开关 → 确认删除
- **修改价格**：点击物品 → 在价格输入框中输入新价格（支持表达式如 `2*100`）

#### 3. 从背包选择物品
- 添加物品后，系统会自动扫描你的背包
- 下拉菜单中显示物品名称和数量
- 选择物品后，系统会自动填充物品信息
- 如果物品含有附魔、自定义名称等特殊数据，会自动保存SNBT

#### 4. 价格设置
- 价格支持数学表达式计算（如 `10*5+20`）
- 价格必须为正整数
- 修改后立即生效，无需重启

### 注意事项
- ⚠️ 只有OP（管理员）才能看到"设置系统商店"按钮
- ⚠️ 删除分类会同时删除其中的所有物品，请谨慎操作
- ⚠️ 修改商店配置后，所有玩家的自动售出设置会被清空（系统会广播通知）
- 💡 建议先使用在线编辑器规划好分类结构，再通过GUI添加具体物品
