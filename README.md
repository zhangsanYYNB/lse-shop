# 🛒 商店系统插件 - 使用说明

## 📦 插件概述

商店系统插件旨在为生存服务器提供基本的购买、出售和自动售出功能。目前支持物品分类、搜索、表达式计算等功能。虽然功能还在不断完善中，但基本可以满足日常使用需求。如果在使用过程中遇到问题，欢迎反馈。

> **兼容性说明：** 本插件的 `shopdata.json` 配置文件格式兼容 [TMEssential](https://www.minebbs.com/resources/tmessential.2974/) 的商店配置，本插件正是基于 TMEssential 的商店配置文件格式开发的。如果你之前使用过 TMEssential 的商店功能，可以直接使用原有的配置文件。

---

## 🎯 核心功能

### 1. 购买系统
- 从商店购买物品，使用服务器金币
- 支持分类浏览和搜索
- 支持表达式计算购买数量（如 `2*3+1`）

### 2. 出售系统
- 出售物品获得金币
- 自动检测背包中物品数量
- 支持批量出售

### 3. 自动售出系统
- 设置特定物品自动出售
- 定时检查并自动出售设置的物品
- 可配置检查间隔时间

### 4. 搜索功能
- 按名称搜索物品（目前仅支持精确匹配，模糊匹配功能还在开发中）
- 跨分类搜索

### 5. 分类管理
- 支持分类图标
- 灵活的配置结构
- 多级分类功能：虽然代码中有相关逻辑，但目前还未经过充分测试，建议先使用单级分类

## ⚙️ 配置文件

### 1. 插件配置文件

**位置：** `plugins/shop/config.json`

```json
{
    "AutoSell": true,
    "AutoSellTime": 60
}
```

**配置项说明：**

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `AutoSell` | 布尔值 | `true` | 是否启用自动售出功能 |
| `AutoSellTime` | 数字 | `60` | 自动售出检查间隔（秒） |

---

### 2. 商品数据配置文件

**位置：** `plugins/shop/shopdata.json`

**在线编辑工具：** [shopdata.json 编辑器](https://ai.zhangsanyynb.top/shopdata.html)

#### 配置文件结构

```json
{
    "Buy": [
        {
            "name": "分类名称",
            "type": "group",
            "image": "图标路径",
            "data": [
                {
                    "name": "物品名称",
                    "type": "exam",
                    "image": "图标路径",
                    "data": {
                        "type": "minecraft:物品ID",
                        "aux": 0,
                        "remark": "备注",
                        "money": 价格
                    }
                }
            ]
        }
    ],
    "Sell": [
        // 结构与 Buy 相同
    ]
}
```

#### 字段详细说明

**分类对象（group）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | 字符串 | ✅ | 分类显示名称 |
| `type` | 字符串 | ✅ | 固定值 `"group"` |
| `image` | 字符串 | ❌ | 分类图标路径（可为空） |
| `data` | 数组 | ✅ | 子物品列表 |

**物品对象（exam）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | 字符串 | ✅ | 物品显示名称 |
| `type` | 字符串 | ✅ | 固定值 `"exam"` |
| `image` | 字符串 | ❌ | 物品图标路径（可为空） |
| `data` | 对象 | ✅ | 物品详细信息 |

**物品数据对象（data）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | 字符串 | ✅ | Minecraft 物品ID（如 `minecraft:diamond`） |
| `aux` | 数字 | ❌ | 物品附加值/数据值（目前暂不支持，以后可能会添加） |
| `remark` | 字符串 | ❌ | 备注信息 |
| `money` | 数字 | ✅ | 价格（金币） |

## 🔧 高级功能

### 1. 表达式计算

购买/出售数量支持数学表达式：

```
2*3+1      → 7
10/2       → 5
(2+3)*4    → 20
2^3        → 8
10 mod 3   → 1
```

**支持的运算符：**
- `+` 加法
- `-` 减法
- `*` 乘法
- `/` 除法
- `%` 或 `mod` 取模
- `^` 幂运算
- `()` 括号

**支持的输入格式：**
- 全角/半角数字
- 全角/半角运算符
- 中文括号/英文括号

### 2. 自动售出系统

**工作原理：**
1. 玩家通过商店界面设置要自动售出的物品
2. 系统按配置的时间间隔检查在线玩家
3. 自动出售玩家背包中设置的物品
4. 金币自动添加到玩家账户

**设置方法：**
1. 执行 `/shop open`
2. 选择"自动售出设置"
3. 选择物品分类
4. 开启要自动售出的物品开关

**查看设置：**
```
/shop list    # 查看当前自动售出物品列表
```

### 3. 搜索功能

- 在购买/出售界面点击"搜索"
- 输入物品名称进行搜索
- 搜索结果会显示物品所在分类

> **注意：** 目前搜索功能仅支持精确匹配，暂时还不支持模糊搜索。如果搜索不到结果，请尝试输入完整的物品名称。这个功能后续可能会改进。

## 🛠️ 安装与部署

### 1. 安装步骤

1. 将 `shop.js` 放入 `plugins/` 目录
2. 创建 `plugins/shop/` 目录
3. 将 `shopdata.json` 放入 `plugins/shop/` 目录
4. 可选：创建 `plugins/shop/config.json` 自定义配置

### 2. 配置步骤

1. 编辑 `shopdata.json` 添加商品
   - 可使用在线编辑器：https://ai.zhangsanyynb.top/shopdata.html
2. 编辑 `config.json` 调整插件设置
3. 重启服务器或重新加载插件

### 3. 重载配置

- 修改 `shopdata.json` 后，系统会自动检测变化
- 如果商品配置发生变化，会清空所有玩家的自动售出设置
- 系统会广播通知玩家重新设置

### 📖 使用步骤

#### 步骤1：访问编辑器
打开浏览器，访问 https://ai.zhangsanyynb.top/shopdata.html

#### 步骤2：创建或导入配置
- **新建配置**：点击"新建"按钮开始创建
- **导入配置**：点击"导入"按钮上传现有的 `shopdata.json` 文件

#### 步骤3：编辑商品数据
1. **添加分类**：
   - 点击"添加分类"按钮
   - 输入分类名称（如"矿物"、"食物"）
   - 可选：设置分类图标路径

2. **添加物品**：
   - 在分类下点击"添加物品"
   - 填写物品信息：
     - 名称：显示给玩家的名称
     - 物品ID：Minecraft 物品ID（如 `minecraft:diamond`）
     - 价格：金币价格
     - 图标：可选，纹理路径

3. **编辑属性**：
   - 点击已有物品进行编辑
   - 修改价格、名称等属性
   - 调整物品在分类中的位置

#### 步骤4：导出配置
1. 点击"导出"按钮
2. 下载生成的 `shopdata.json` 文件
3. 将文件放入服务器的 `plugins/shop/` 目录

#### 步骤5：应用配置
1. 重启服务器或重新加载插件
2. 系统会自动检测配置变化
3. 玩家可以开始使用更新后的商店

### 💡 使用技巧

#### 物品ID查找
- 使用游戏内 `/give` 命令查看物品ID
- 参考 Minecraft Wiki 物品ID列表
- 常用物品ID：
  - 钻石：`minecraft:diamond`
  - 铁锭：`minecraft:iron_ingot`
  - 金锭：`minecraft:gold_ingot`
  - 绿宝石：`minecraft:emerald`
  - 红石：`minecraft:redstone`

#### 价格设置建议
- 购买价格 > 出售价格（防止刷金）
- 稀有物品设置较高价格
- 基础资源设置较低价格
- 参考服务器经济平衡

#### 图标设置
- 使用 Minecraft 纹理路径
- 格式：`textures/items/物品名.png`
- 示例：`textures/items/diamond.png`
- 可以为空，使用默认图标

### ⚠️ 注意事项

1. **备份配置**：修改前建议备份原始 `shopdata.json` 文件，以防万一
2. **格式验证**：请确保导出的 JSON 格式正确
3. **物品ID**：需要使用完整的 Minecraft 物品ID
4. **编码格式**：建议使用 UTF-8 编码保存文件
5. **重启生效**：修改配置后可能需要重启服务器才能生效
6. **aux字段**：目前暂不支持物品附加值（aux），这个功能计划在后续版本添加
7. **多级分类**：虽然代码中有相关逻辑，但还未经过充分测试，建议先使用单级分类

### 🔧 常见问题

#### Q1: 为什么自动售出设置被清空了？
A: 当 `shopdata.json` 文件内容发生变化时，系统会自动清空所有自动售出设置，这是为了确保数据的一致性，还请理解。

#### Q2: 如何添加新物品？
A: 可以编辑 `shopdata.json` 文件，在对应的 `Buy` 或 `Sell` 数组中添加新的物品配置。推荐使用在线编辑器，会方便很多。

#### Q3: 支持哪些物品图标？
A: 支持 Minecraft 纹理路径，如 `textures/items/diamond.png`。也可以留空，会使用默认图标。

#### Q4: 如何修改自动售出检查间隔？
A: 编辑 `plugins/shop/config.json` 文件，修改 `AutoSellTime` 值（单位：秒）即可。

#### Q5: 表达式计算支持哪些功能？
A: 支持加减乘除、幂运算、取模、括号，以及全角/半角字符自动转换，应该能满足大部分计算需求。

#### Q6: 编辑器无法加载怎么办？
A: 可以检查一下网络连接，尝试刷新页面，或者换个浏览器试试。

#### Q7: 如何修改已有物品的价格？
A: 在编辑器中找到对应物品，点击编辑按钮修改价格，然后重新导出配置即可。

#### Q8: 导出的文件无法使用？
A: 请检查 JSON 格式是否正确，确保没有语法错误，文件编码建议使用 UTF-8。

#### Q9: 可以同时编辑购买和出售吗？
A: 是的，编辑器支持同时编辑 `Buy` 和 `Sell` 两个部分。

#### Q10: 如何恢复默认配置？
A: 可以使用编辑器的"重置"功能，或者从备份恢复原始文件。

#### Q11: 为什么aux字段不生效？
A: 非常抱歉，目前插件暂不支持aux（物品附加值）功能，这个功能正在计划中，后续版本可能会添加。

#### Q12: 多级分类可以使用吗？
A: 代码中虽然有多级分类的相关逻辑，但目前还未经过充分测试。为了稳定性考虑，建议暂时先使用单级分类。
